## 5.# Subject Management System

A simple Python program for managing school subjects and tracking topic progress.

## Features

- Add subjects
- Remove subjects
- Add topics to subjects
- Mark topics as completed
- View subject information
- Track topic completion percentage
- Store teacher names
- Set subject difficulty

## How to Run

1. Install Python.
2. Save the program as `subject_manager.py`.
3. Open a terminal in the project folder.
4. Run:

python subject_manager.py
